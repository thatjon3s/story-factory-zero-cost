# Illustrated production assets

These reusable series assets were generated on 2026-07-26 for the zero-cost
storybook renderer. They replace the procedural circle-and-rectangle artwork.

- `playground-lake.png`: cinematic 16:9 playground and lakeside environment
- `mia-poses.png`: six transparent, identity-consistent performance poses
- `noah-poses.png`: six transparent, identity-consistent performance poses
- `props.png`: transparent shovel, ball, paper boat, and picnic basket

The source prompts specify polished European children's-book illustration,
natural faces and hands, consistent wardrobe, painterly texture, and separated
animation poses. Green-screen source sheets were processed with a soft alpha
matte and despill before being committed.
